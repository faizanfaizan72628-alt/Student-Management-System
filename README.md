# Student Management Table
A beginner-friendly Student Management System built using HTML, CSS, and JavaScript.
## Features
- Add new student records
- Edit existing student details
- Delete student records
- Search by student name, roll number, or grade
- Automatically calculate student grades
- Validate marks and prevent duplicate roll numbers
- Responsive table design
## Technologies Used
- HTML5
- CSS3
- JavaScript
## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
## Note
Student records are stored in JavaScript memory.
They reset when the page is refreshed.
